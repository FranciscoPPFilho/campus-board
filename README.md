# CampusBoard 🎓

O **CampusBoard** é uma plataforma centralizada para a comunidade acadêmica da **UNIPÊ**, projetada para resolver a fragmentação de informações (eventos, vagas e recados) que hoje circulam de forma desorganizada em murais físicos ou grupos de mensagens.

## 🚀 Objetivo
Centralizar a comunicação universitária em um feed digital dinâmico e categorizado, facilitando o acesso à informação para estudantes e professores.

## 🛠️ Tecnologias Utilizadas
* **Framework:** Flutter (Google)
* **Linguagem:** Dart
* **Plataforma:** Multiplataforma (Android, iOS e Web)
* **IDE Recomendada:** VS Code ou Android Studio

## ✨ Funcionalidades Planejadas
1. **Autenticação:** Login e cadastro exclusivo com e-mail institucional.
2. **Feed Digital:** Listagem cronológica de publicações.
3. **Categorização:** Filtros por Evento, Vaga, Recado e Achado/Perdido.
4. **Gestão de Posts:** Criação e exclusão de publicações pelo próprio autor.
5. **Perfil:** Espaço dedicado para informações do usuário e navegação.

## 🎨 Identidade Visual (UI/UX)
Baseada na paleta institucional da UNIPÊ:
* **Cor Primária:** Azul Escuro 🔵
* **Destaque/Ação:** Amarelo Dourado 🟡
* **Estilo:** Moderno, clean e institucional.
